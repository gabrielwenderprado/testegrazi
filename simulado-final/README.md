# Simulado — Desenvolvimento Web

## Arquivo recomendado

Use o `index.html`. Ele é autossuficiente e já contém todo o CSS e JavaScript dentro dele. Para publicar no GitHub Pages, basta enviar o `index.html` para a raiz do repositório.

## Arquivos separados

`styles.css` e `app.js` são cópias organizadas do estilo e do JavaScript. O `index.html` principal não depende deles, então não haverá erro de CSS caso você envie somente o HTML.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.
5. Clique em **Save** e abra o link gerado pelo GitHub.
